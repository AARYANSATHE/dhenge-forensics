# Dhenge Forensic Consultancy Website

A professional, multi-page forensic consultancy website built with a dark navy and gold aesthetic. This project features high-precision scientific disciplines, case studies, and a modern, responsive design.

## 🚀 Live Demo
View the live website here: [https://aaryansathe.github.io/dhenge-forensics/](https://aaryansathe.github.io/dhenge-forensics/)

## ✨ Features
- **9 Professional Pages**: Homepage, Services, About, Team, Cases, Contact, Privacy, Terms, and Disclaimer.
- **Dark Navy & Gold Aesthetic**: A formal, authoritative color palette tailored for forensic and legal professionals.
- **Responsive Design**: Fully optimized for Desktop, Tablet, and Mobile devices.
- **Interactive Elements**:
  - Tab-switched service disciplines.
  - Case study filtering system.
  - FAQ accordion.
  - Scroll-reveal animations.
  - Validated contact form.
- **Fast Performance**: Built with clean HTML5, CSS3, and vanilla JavaScript.

## 📂 Project Structure
```text
dhenge-forensics/
├── css/
│   └── style.css      # Main stylesheet with theme variables
├── js/
│   └── main.js       # Interactivity, animations, and form handling
├── index.html        # Homepage
├── services.html     # Service disciplines with tabs
├── about.html        # Company history and mission
├── team.html         # Expert witness profiles
├── cases.html        # Filterable case studies
├── contact.html      # Contact form and FAQs
├── privacy.html      # Privacy policy
├── terms.html        # Terms of service
└── disclaimer.html   # Legal disclaimer
```

## 🛠️ Installation & Deployment
1. **Clone the repository**:
   ```bash
   git clone https://github.com/AARYANSATHE/dhenge-forensics.git
   ```
2. **Open locally**:
   Simply open `index.html` in any modern web browser.
3. **Deploy**:
   Upload the files to any static hosting provider (GitHub Pages, Netlify, Vercel, etc.).
